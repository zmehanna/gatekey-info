Retrouvez PrivateGateKey sur votre téléphone Android, avec la même identité bleu nuit et or que sur iPhone. La version bêta inclut une démonstration locale, également utilisable avec BlueStacks.

Sur iPhone : le bouton « Tester Android » ouvre un Android virtuel en mode démonstration hors ligne, sans accès aux équipements. Il sera activé uniquement quand la version correspondante sera disponible.

APK de test Android · nécessite Android 9 ou ultérieur. La dernière version uniquement est hébergée par GitHub Releases. Installer en trois étapes

01

Télécharger l'APK

Enregistrez le fichier sur votre téléphone Android ou votre ordinateur équipé de BlueStacks.

02

Installer PrivateGateKey

Ouvrez le fichier sur Android ou glissez-le dans la fenêtre BlueStacks. Autorisez l'installation depuis cette source si demandé.

03

Activer ou explorer

Un téléphone compatible peut activer une invitation. Sur BlueStacks, utilisez « Essayer le mode démonstration » pour parcourir l'interface sans action réelle.

🔒Sécurité : sur un téléphone Android déjà déverrouillé et autorisé, le passage dégagé, le portail visible et le maintien de 1,5 seconde restent obligatoires. Aucun code, PIN ni biométrie supplémentaire n'est demandé au déclenchement. Les anciennes associations exigent une réactivation unique. BlueStacks et Appetize.io restent limités à une démonstration hors ligne. Cette version bêta n'a pas encore été validée sur un portail physique.
